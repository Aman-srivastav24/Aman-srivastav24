### What I'm working on

**[AI Support Triage API](https://github.com/Aman-srivastav24/ai-support-triage)** — a FastAPI backend that triages
support tickets: classifies each one, retrieves the relevant documentation by vector
similarity search over pgvector, drafts a cited reply through a LangGraph agent, and
escalates to a human when it can't ground the answer.

It escalates because I watched it confidently invent a support process that appears
nowhere in the documentation — then measured that similarity scores alone can't
separate answerable questions from unanswerable ones.

`FastAPI` · `Pydantic v2` · `SQLAlchemy 2.0` · `Alembic` · `PostgreSQL + pgvector` ·
`Redis` · `LangGraph` · `SSE streaming` · `JWT + RBAC` · `pytest` · `Docker`
